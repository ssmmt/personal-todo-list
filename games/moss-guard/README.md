# 苔光守卫

解压后打开 `index.html` 就能玩。请保留同一文件夹中的 CSS、JavaScript 和 `assets/`。

## 操作

- WASD 或方向键移动。
- 按空格攻击，或者点击战场朝该位置挥击。
- 按 P 暂停或继续。手机可用战场下方的方向键和攻击按钮。
- 击退三波怪物即可通关。过关时，如果生命值未满，会回复一格。

## 换素材

游戏右上角的「替换素材」支持上传 PNG、WebP 或 JPG。角色和怪物建议使用透明底图片。上传的图片保存在当前浏览器，可以随时恢复默认。

如果想把自定义图片当作每个人进入网页时的默认素材，可替换以下文件，或修改 `config.js` 中对应的 `source` 路径。

| 文件 | 用途 |
| --- | --- |
| `assets/guardian.webp` | 角色 |
| `assets/slime.webp` | 怪物 |
| `assets/arena.webp` | 地图背景 |

地图在手机上会裁切显示，把主要图案放在画面中间。波次数量、速度和攻击参数也在 `config.js` 里。
